Bookmarks

URL・ファイル・フォルダをまとめて管理するデスクトップアプリです。

1 / 9
01 — Overview

Bookmarks でできること

  • URL とローカルのファイル・フォルダを、まとめて管理できます。
  • タイトル・URL・メモのキーワード検索や、タグで簡単に見つかります。
  • Ctrl + Alt + Space（変更可）で、どこからでも呼び出せます。
  • ブックマークごとに、任意のショートカットキーを割り当てられます。
  • ブラウザ拡張機能やエクスプローラ連携で、簡単に追加できます。

02 — Organize

整理して使う

  • ピン留めで、よく使うブックマークを最上部に固定できます。
  • カラム数は1〜4列で切り替えられ、自動保存されます。
  • 追加日時・タイトル・アクセス数・カスタム順で並び替えられます。
  • ドラッグ＆ドロップで、順序を自由に並び替えられます。
Bookmarks3 / 9
03 — Search & Tag

検索とタグ

  • タイトル・URL・メモを対象にキーワード検索できます。
  • 文字キーを打ち始めるだけで、検索欄にフォーカスして入力が始まります。
  • タグをクリックで絞り込み、Ctrl + クリックで複数選択もできます。
  • URL やタイトルの条件に応じて、タグが自動で付くルールを設定できます。

04 — Import / Export

インポート・エクスポート・バックアップ

  • ブラウザのブックマークHTMLをインポートできます。
  • 現在の一覧をHTML形式でエクスポートできます。
  • 全データをJSONでバックアップ・復元できます。
  • 確認入力付きで、全データを削除できます。

05 — Integrations

連携機能

  • 右クリックやドラッグ＆ドロップで、ファイル・フォルダを登録できます。
  • ブラウザ拡張機能から、閲覧中のページをワンクリックで保存できます。
  • 拡張機能では、保存済みURLの重複も自動で検知します。
  • 各ブックマークにメモを添付でき、検索対象にもなります。
Bookmarks6 / 9
06 — Shortcuts

キーボードショートカット

  • Ctrl + Alt + Space で、アプリを前面に表示します。
  • 文字キーを打つと、検索欄にフォーカスして入力が始まります。
  • Tab や矢印キーで、カード間をフォーカス移動します。
  • Esc で、モーダルを閉じたり操作を取り消せます。

ブックマークごとに個別のショートカットキーも設定できます（修飾キーが1つ以上必要です）。

07 — Always Available

常駐と自動起動

  • ウィンドウを閉じてもアプリは終了せず、システムトレイに常駐します。
  • トレイアイコンやショートカットで、いつでも呼び出せます。
  • Windows のログイン時にも自動的に起動します。
  • トレイメニューの「Quit」を選ぶと、完全に終了できます。

08 — Getting Started

導入方法

  1. Microsoft Store（「Bookmarks & Tags」）からインストールします。配布されたインストーラ（NSIS / MSI）を使うこともできます。
  2. インストール後、タスクトレイに Bookmarks のアイコンが表示されます。
  3. Ctrl + Alt + Space（初期値）を押して、最初のブックマークを追加してみてください。
  4. ブラウザ拡張機能は Microsoft Edge アドオンストアからインストールできます（アプリ内ヘルプからZIPを取得して読み込むことも可能です）。

データはすべてこのPC内の SQLite ファイル（%APPDATA%\com.yukihirosakuda.bookmarks\bookmarks.db）に保存され、外部サーバーには送信されません。Store版とインストーラ版は同じ保存先を使うため、入れ替えてもブックマークはそのまま引き継がれます。PCを移行する際は Settings → Data → Backup / Restore をご利用ください。

詳しい使い方はアプリ内のヘルプ（? ボタン）をご覧ください。
