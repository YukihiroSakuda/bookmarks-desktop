# Store 掲載情報 — 0.1.8

Partner Center の「この更新プログラムの新機能（What's new in this version）」欄に貼り付ける文章。

## 日本語

```
■ 新機能
・一覧のキーボード操作を強化しました。Home / End で先頭・最後尾のカードへ移動、検索欄で ↓ を押すと最初のカードへ移動できます。
・検索履歴を Alt+↓ / Alt+↑ で選択し、Enter で確定できるようになりました。
・ショートカットで呼び出したとき、検索欄をクリアして履歴を閉じるようにしました。
・設定画面に About を追加しました。バージョン表示と、各種リンクを確認できます。

■ 改善
・ヘルプに「データの保存先」を追加しました。データはすべてお使いのPC内に保存されます。
・ブラウザ拡張機能を Microsoft Edge アドオンストアからインストールできるようになりました。
```

## English

```
New
- Improved keyboard navigation: Home / End jump to the first / last card, and Down from the search box moves to the first card.
- Search history can be selected with Alt+Down / Alt+Up and confirmed with Enter.
- The search box is cleared and the history dropdown closed when the app is summoned with the global shortcut.
- Added an About section in Settings with the app version and links.

Improved
- Help now documents where your data is stored. Everything stays on your own PC.
- The browser extension can now be installed from the Microsoft Edge Add-ons store.
```

## スクリーンショット

UI 変更は Settings の About ブロック追加とヘルプの改訂のみ。既存のスクリーンショット（`promo/screenshots/`）はメイン画面中心なので、差し替えは不要。
