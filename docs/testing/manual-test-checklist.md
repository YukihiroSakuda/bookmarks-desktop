## ファイルショートカット（クイックアクセス用フォルダ）

### 生成と追従

- [ ] 既定では OFF で、フォルダが作られていない
- [ ] Settings → File shortcuts を On にすると生成先フォルダができ、ローカルのファイル/フォルダのブックマーク分だけショートカットが並ぶ
- [ ] **URL のブックマークは出力されない**
- [ ] ショートカットをダブルクリックすると、アプリでカードをクリックしたときと同じものが開く（ファイル=既定アプリ / フォルダ=Explorer）
- [ ] ローカルファイルのブックマークを追加すると、少し遅れてショートカットが増える
- [ ] ブックマークを削除するとショートカットも消える
- [ ] ブックマークのパスを変更すると、古いショートカットが消えて新しいものができる（両方残らない）
- [ ] ショートカットを手で削除しても、次の同期で復活する
- [ ] 大量インポート直後でも、同期が何度も走らず1回で収束する

### 名前

- [ ] ショートカット名は**実ファイル名**（拡張子込み）で、ブックマークのタイトルではない
- [ ] 別フォルダにある同名ファイルを2つブックマークすると、片方が `見積書 (案件A).xlsx` のように親フォルダ名付きになる
- [ ] ブックマークのタイトルはショートカットのコメント（ツールチップ）に入っている

### 並び順

- [ ] エクスプローラーで「更新日時」の降順にすると、最近開いたブックマークが上に来る
- [ ] ブックマークを開き直すと、そのショートカットの更新日時が進む

### ファイル選択ダイアログ（この機能の目的）

- [ ] **Outlook の添付**でフォルダを開くとショートカットが見え、選ぶと実体が添付される
- [ ] **Excel の「開く」**（フィルタが `*.xlsx` 等）でもショートカットが一覧に出る
- [ ] **Chrome のアップロード**でも同様に選択できる
- [ ] フォルダのショートカットをダブルクリックすると、その場所に移動できる

### クイックアクセス

- [ ] 「Pin to Quick Access」でクイックアクセスに追加され、ボタンが「Unpin from Quick Access」に変わる
- [ ] もう一度押すと解除され、ボタンの表示が戻る
- [ ] エクスプローラー側で手動でピン留め/解除したあと、設定画面を開き直すとボタンの表示が実態と一致する
- [ ] ピン留めした状態でファイル選択ダイアログを開くと、左ペインから1クリックで辿り着ける

### 安全性（重要）

- [ ] 生成先に自分のファイル（`.docx` など）を置いてから同期しても、そのファイルは消えない
- [ ] 生成先に自分で作った `.lnk` を置いても消えない
- [ ] 機能を Off にすると、生成したショートカットとフォルダが消え、**クイックアクセスのピンも外れる**
- [ ] Off にしたとき、生成先に自分のファイルが残っていればフォルダは削除されない
- [ ] 存在しないファイルを指すブックマークがあっても、他のショートカットは作られる（1件スキップされるだけ）

### ストア（MSIX）版

- [ ] MSIX 版でも `%USERPROFILE%\Bookmarks` に実際に書き込まれる（パッケージ内に隔離されない）
- [ ] MSIX 版と GitHub Releases 版で生成先が同じ
